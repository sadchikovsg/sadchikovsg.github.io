# Привет, я Сергей Садчиков 👋

**DevOps / Platform Engineer**

Моя ежедневная работа — это построение надежных, автоматизированных и безопасных платформ для разработки. Я превращаю хаотичные ручные операции в предсказуемые, масштабируемые процессы, фокусируясь на том, что действительно важно для бизнеса: стабильности, скорости доставки кода (TTM) и полном контроле над инфраструктурой.

**Ключевые направления моей работы:**
- 🚀 **Оптимизация CI/CD:** Ускорение пайплайнов, кэширование, внедрение единых шаблонов и практик DevSecOps (Kaniko, SAST/SCA, подпись образов).
- 🏣 **Infrastructure as Code (IaC):** Декларативное управление облачными ресурсами (Yandex Cloud, AWS) и конфигурациями через Terraform и Ansible.
- 🔍 **Observability & Reliability:** Построение систем мониторинга (Prometheus/Grafana), настройка алертинга и обеспечение высокой доступности (HA) критических сервисов.

### 📚 Мой инженерный подход

Мой стиль работы сформирован глубоким пониманием того, как работают операционные системы и сети «под капотом». Опыт администрирования гетерогенных сред дал мне прочный фундамент для решения сложных задач траблшутинга (cgroups, namespaces, сетевой стек, DNS), с которыми часто не справляются инструменты "из коробки". 

Сегодня я применяю этот фундамент для построения современных Cloud Native решений, делая инфраструктуру не просто работающей, но и экономически эффективной, безопасной и простой в поддержке.
